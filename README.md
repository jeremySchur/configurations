# configurations

My terminal setup: zsh with [Oh My Zsh](https://ohmyz.sh) and the [Powerlevel10k](https://github.com/romkatv/powerlevel10k) prompt, running in WSL (Ubuntu) inside Windows Terminal or in Terminal.app on macOS, with the Dracula colors and a Powerline font. It also sets up pyenv (Python) and nvm (Node).

## What's in here

| File | Installed to | What it is |
|---|---|---|
| `shell/zshrc` | `~/.zshrc` | Main zsh config: Oh My Zsh, theme, plugins, nvm, pyenv |
| `shell/p10k.zsh` | `~/.p10k.zsh` | Prompt config (generated by `p10k configure`) |
| `shell/dircolors` | `~/.dircolors` | Solarized Dark colors for `ls` ([source](https://github.com/seebi/dircolors-solarized)) |
| `shell/bashrc` | `~/.bashrc` | Bash config. Only used if you run `bash` by hand |
| `oh-my-zsh/aliases.zsh` | `~/.oh-my-zsh/custom/aliases.zsh` | Aliases |
| `windows-terminal/settings.json` | Windows Terminal's `settings.json` | Ubuntu profile: font, Dracula colors, 90% opacity |
| `install.sh` | | Installs Oh My Zsh, Powerlevel10k and the plugins, links the files above, and makes zsh the login shell |

`install.sh` **links** the files instead of copying them. Editing `~/.zshrc` therefore edits the file in this repo, and you only need to commit and push. Windows Terminal's settings are the one exception: Windows can't follow a link into WSL, so that file is a copy.

Oh My Zsh plugins in use: [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions) (gray suggestions from your history as you type; press → to accept) and [zsh-syntax-highlighting](https://github.com/zsh-users/zsh-syntax-highlighting) (colors commands green or red as you type). `install.sh` clones both.

## Setting up a Mac

1. Install the Xcode command line tools (`xcode-select --install`) and [Homebrew](https://brew.sh).
2. Clone this repo and run the installer:

   ```bash
   mkdir -p ~/Repos && cd ~/Repos
   git clone https://github.com/jeremySchur/configurations.git
   cd configurations
   ./install.sh
   ```

   On macOS the installer also runs `brew install` for GNU `coreutils`, so `ls` and `dircolors` work like on Linux (`~/.zshrc` puts them first in `PATH`), and for the **MesloLGS NF** font.
3. Terminal.app colors: import [Dracula for Terminal.app](https://github.com/dracula/terminal-app) by opening `Dracula.terminal`. Then in **Terminal > Settings > Profiles > Dracula**, set the font to **MesloLGS NF**, size 16, and click **Default**. For the slight transparency, click the **Background** color under **Text** and set **Opacity** to 90%. (iTerm2 works too; set the same font there.)
4. pyenv and nvm:

   ```bash
   brew install pyenv openssl@3 readline sqlite3 xz zlib tcl-tk
   PROFILE=/dev/null bash -c "$(curl -fsSL https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.4/install.sh)"
   exec zsh
   pyenv install 3.15 && pyenv global 3.15
   nvm install --lts && nvm alias default 'lts/*'
   ```

   `PROFILE=/dev/null` stops the nvm installer from appending to `~/.zshrc`, which is this repo's file.
5. The `zshconfig`, `p10kconfig` and `aliases` aliases need VS Code's `code` command. `~/.zshrc` adds it to `PATH` automatically when VS Code is in `/Applications`.

If Terminal doesn't list **MesloLGS NF** after the install, macOS hasn't registered the font yet. Open each `~/Library/Fonts/MesloLGS NF*.ttf` file and click **Install** in Font Book, then restart Terminal.

## Setting up a new Windows (WSL) machine

Do these in order.

### 1. Install WSL, Ubuntu and Git (Windows)

In PowerShell **as Administrator**:

```powershell
wsl --install -d Ubuntu
winget install Git.Git
```

Restart when it asks. Then open **Ubuntu** from the Start menu and create your Linux username and password. Windows Terminal comes with Windows 11. On Windows 10, get it from the Microsoft Store.

### 2. Install the Powerline fonts (Windows)

The prompt's arrow-shaped segments use special characters that only exist in "Powerline" fonts. Without one, the prompt shows boxes and question marks. Install the font on **Windows**, not in Ubuntu, because Windows Terminal is what draws the text.

In a normal (not admin) PowerShell:

```powershell
git clone https://github.com/powerline/fonts.git $HOME\Repos\fonts
cd $HOME\Repos\fonts
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1 "Meslo LG M*"
```

That installs **Meslo LG M for Powerline**, the font the terminal uses. Running `.\install.ps1` with no argument installs all ~100 Powerline fonts.

Without git: download the four `Meslo LG M ... for Powerline.ttf` files from the [Meslo Slashed folder](https://github.com/powerline/fonts/tree/master/Meslo%20Slashed), select them, right-click, then **Install**.

> The prompt config uses `POWERLEVEL9K_MODE=powerline`, so a plain Powerline font is enough. You only need a Nerd Font if you rerun `p10k configure` and pick a style with icons.

### 3. Install the base packages (Ubuntu)

Open the Ubuntu terminal:

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y zsh git curl
```

### 4. Clone this repo and run the installer (Ubuntu)

```bash
mkdir -p ~/Repos && cd ~/Repos
git clone https://github.com/jeremySchur/configurations.git
cd configurations
./install.sh
```

The installer:

1. Installs Oh My Zsh.
2. Clones Powerlevel10k, zsh-autosuggestions and zsh-syntax-highlighting into `~/.oh-my-zsh/custom/`.
3. Links every file in the table above into your home folder. Any file it replaces is moved to `~/.dotfiles-backup/<date-time>/`.
4. Makes zsh your login shell with `chsh`, which asks for your Linux password.

It's safe to run again. Steps that are already done get skipped.

### 5. Apply the Windows Terminal settings

Open Windows Terminal once so its settings file exists, then close it. From Ubuntu:

```bash
WT_DIR="$(wslpath "$(cmd.exe /c 'echo %LOCALAPPDATA%' 2>/dev/null | tr -d '\r')")/Packages/Microsoft.WindowsTerminal_8wekyb3d8bbwe/LocalState"
cp "$WT_DIR/settings.json" "$WT_DIR/settings.json.bak"
cp ~/Repos/configurations/windows-terminal/settings.json "$WT_DIR/settings.json"
```

Open Windows Terminal again and check the Ubuntu tab. If it doesn't have the dark purple Dracula look, or you see two Ubuntu entries, set it by hand. Go to **Settings > Profiles > Ubuntu > Appearance** and set:

- Color scheme: **Dracula** (the copied file adds it)
- Font face: **Meslo LG M for Powerline**, size **12**
- Background opacity: **90%**

Then under **Settings > Startup**, set the default profile to **Ubuntu**.

### 6. Open a new terminal and check

Close every terminal and open a new Ubuntu tab. You should see the two-line rainbow prompt, drawn with `╭─` and `╰─➤`.

```bash
echo $SHELL    # should print /usr/bin/zsh
```

- **Boxes or `?` in the prompt:** the font isn't set. Redo step 2 or 5.
- **Still a plain bash prompt:** `chsh` didn't run. Run `chsh -s $(which zsh)`, then close the terminal fully. In stubborn cases, run `wsl --shutdown` from PowerShell first.

### 7. Install pyenv and nvm (Ubuntu)

`~/.zshrc` already loads both, so you only install them here.

**pyenv (Python):**

```bash
sudo apt install -y make build-essential libssl-dev zlib1g-dev libbz2-dev libreadline-dev \
  libsqlite3-dev libncursesw5-dev xz-utils tk-dev libxml2-dev libxmlsec1-dev libffi-dev liblzma-dev
curl -fsSL https://pyenv.run | bash
exec zsh
pyenv install 3.15
pyenv global 3.15
```

**nvm (Node):**

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.4/install.sh | bash
exec zsh
nvm install --lts
nvm alias default 'lts/*'
```

Both installers might print "add these lines to your shell config" instructions. Skip them, because `~/.zshrc` already has those lines.

### 8. Set your git identity

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

## Moving an existing machine onto this repo

`install.sh` replaces `~/.oh-my-zsh/custom/aliases.zsh` with this repo's version. The original goes to `~/.dotfiles-backup/`, but nothing loads from there. If a machine has its own aliases or functions in that file that you want to keep, first move them to a new file in the same folder, such as `~/.oh-my-zsh/custom/local.zsh`. Oh My Zsh loads every `*.zsh` file in `custom/` automatically.

## Making changes later

- Edit the configs with the built-in aliases: `zshconfig`, `p10kconfig` and `aliases` open them in VS Code. Because the files are links, you're editing this repo directly.
- `p10k configure` rewrites `~/.p10k.zsh`, which is also the repo's file.
- To save your changes:

  ```bash
  cd ~/Repos/configurations && git add -A && git commit -m "Update config" && git push
  ```

- If you change Windows Terminal settings, copy them back into the repo. `WT_DIR` comes from step 5.

  ```bash
  cp "$WT_DIR/settings.json" ~/Repos/configurations/windows-terminal/settings.json
  ```

- Updating: `omz update` updates Oh My Zsh. The prompt theme and plugins update separately:

  ```bash
  git -C ~/.oh-my-zsh/custom/themes/powerlevel10k pull
  git -C ~/.oh-my-zsh/custom/plugins/zsh-autosuggestions pull
  git -C ~/.oh-my-zsh/custom/plugins/zsh-syntax-highlighting pull
  ```

## Undoing the install

`install.sh` moves every file it replaced into `~/.dotfiles-backup/<date-time>/`. To go back, delete the link (`rm ~/.zshrc`) and move the backup into place. To make bash the login shell again, run `chsh -s /usr/bin/bash`.
